# What's New

Here is a summary of the latest visual improvements, performance upgrades, and user-friendly features introduced in this release.

---

## Latest Version Highlights

### 1. Fresh, Dynamic Profile Portraits
- Every generated persona now receives a distinct portrait photo that dynamically updates with every click.
- Multi-network photo delivery ensures pictures load quickly and smoothly on any internet connection.

### 2. Expanded 24-Country Support
- Authentic name sets, street addresses, postal formats, and phone numbers are now available across 24 countries.
- Improved geographical consistency ensures city, state, province, and postal codes match authentic localized formats.

### 3. Streamlined Bulk Generator
- You can now synthesize up to 100 profiles in a matter of seconds.
- Added clean, 1-click export options for CSV spreadsheets, JSON data, and database SQL formats.

### 4. Interactive Quick-Copy & Feedback
- Tap or click any field to copy it with instant checkmark feedback, saving time when filling out test forms.
- Dedicated download buttons allow you to save individual portrait images directly to your computer or phone.

### 5. Polished Mobile Experience & Theme Switcher
- Re-architected mobile layout ensures buttons, cards, and dropdowns are comfortable to tap on smaller screens.
- Smooth theme toggle allows effortless switching between high-contrast light mode and easy-on-the-eyes dark mode.
