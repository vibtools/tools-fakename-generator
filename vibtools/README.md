# VibTools Workspace Hub

This folder (`/vibtools`) is the standardized **VibTools Workspace Hub** for this repository. It houses the project manifest (`vibtools.json`), high-resolution branding assets, and non-technical documentation designed for creators, catalog dashboards, and non-developer end users.

> **Reusable Standard:** You can copy this entire `/vibtools/` folder structure into any GitHub repository or application to enable instant catalog indexing, 1-click dashboard imports, rich social share cards, and zero-code user onboarding.

---

## 📁 Standard Directory Structure

```text
vibtools/
├── README.md               # Hub documentation and reuse guide (this file)
├── vibtools.json           # Canonical project manifest (adheres to vibtools.schema.json)
├── quick-start.md          # 3-step beginner guide for non-technical users
├── features.md             # Non-technical product overview and capabilities
├── faq.md                  # Plain-language Frequently Asked Questions
├── whats-new.md            # Release highlights and recent visual updates
└── assets/
    ├── og-image.png        # Social OpenGraph card (1200x630, 16:9)
    ├── logo.png            # Square brand icon / logo (512x512, 1:1)
    ├── thumbnail.png       # Catalog banner thumbnail (800x450, 16:9)
    └── screenshot.png      # Workspace UI preview screenshot (1200x675)
